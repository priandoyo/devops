# DevOps, Software Testing & Engineering Labs

A collection of small projects, practical experiments, workshops, and technical demonstrations covering DevOps, software engineering, IT governance, automation, and technology. This repository serves as a hands-on learning space for exploring different technologies, building prototypes, testing applications, and experimenting with practical IT solutions.

## Areas of Exploration

| Area | Topics |
|---|---|
| DevOps & CI/CD | Automation, deployment, GitHub Actions |
| Software Testing | Functional, integration, and performance testing |
| API Engineering | REST APIs, API integration, service testing |
| Programming | Python, Flask, scripting, application development |
| Database | SQLite, SQL, data management |
| Automation | Test automation, workflow automation |
| IT Governance | Continuous assurance, IT controls, technical validation |

## Projects & Workshops

### 1. Software Testing & Performance Engineering

**[JMeter Workshop](https://github.com/priandoyo/devops/blob/main/jmeter_workshop.ipynb)**

A Google Colab workshop demonstrating functional and performance testing of a simulated banking API using Python, Flask, and Apache JMeter. Includes automated test execution, response-time analysis, and HTML reporting.

- Technologies: Python, Flask, Apache JMeter
- Focus: Functional testing and performance testing
- Environment: Google Colab

**[MiniBank Integration Testing Lab](https://github.com/priandoyo/devops/blob/main/minibank_integration_testing_lab.ipynb)**

A hands-on banking integration testing lab demonstrating end-to-end API transactions, automated functional testing, and performance testing.

- Technologies: Python, Flask, SQLite, pytest, Apache JMeter
- Focus: API integration, transaction validation, and load testing
- Environment: Google Colab

## Running the Projects

Most notebooks are designed to run directly in Google Colab without requiring a local development environment.

1. Open a project notebook from the repository.
2. Select **Open in Colab** or upload the notebook to Google Colab.
3. Follow the instructions inside the notebook.
4. Execute the cells sequentially.
5. Review the outputs, test results, and reports.

## Repository Philosophy

This repository follows a simple approach:

- **Learn by doing:** Focus on practical implementation rather than theory alone.
- **Keep it simple:** Build small, understandable, and reusable examples.
- **Experiment:** Explore different technologies and engineering approaches.
- **Share knowledge:** Document experiments and make them accessible.
- **Continuous learning:** Expand and improve projects over time.

## Disclaimer

Projects in this repository are intended for educational, experimental, and demonstration purposes. Banking applications and transaction scenarios are simulated. They are not intended for production use or real financial transactions.
